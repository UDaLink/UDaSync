存储服务

四个服务任选其一。切换不会删除另一边的云端数据；当前服务需要单独连接。

连接坚果云

UDaSync 使用坚果云提供的 WebDAV 服务存取书签，不需要 UDaSync 自己的账号。

账号信息

未连接

请使用坚果云「账户信息 → 安全选项 → 第三方应用管理」里生成的应用密码，不要填账号主密码。 应用密码可以随时单独吊销，主账号不受影响。凭证只保存在本机浏览器配置中。

云端目录

书签快照保存在坚果云 WebDAV 根目录下的 /UDaSync/，其中 devices/ 每台设备一个文件， backups/ 保留最近 10 份自动备份。

注意：坚果云 WebDAV 只认真实 UTF-8 路径，浏览器会把中文路径做百分号编码导致 404， 因此云端目录名固定为 ASCII 的 UDaSync，请勿改成中文。

连接通用 WebDAV

连接任意支持 Basic Auth 的 WebDAV 服务，例如 123 云盘、Nextcloud、Synology、InfiniCLOUD、Koofr 等。

账号信息

未连接

填到 WebDAV 根路径为止，例如 Nextcloud 的 https://cloud.example.com/remote.php/dav/files/你的用户名/。

优先使用服务商提供的应用密码，不要填主密码。凭证只保存在本机浏览器配置中。 通用 WebDAV 目前只支持 Basic Auth；仅提供 Digest 或 OAuth 的服务暂不支持。

HTTP 地址只建议在可信局域网使用；公网请使用 HTTPS。首次测试或保存时，浏览器会请求访问该服务器的权限。

云端目录

书签快照保存在 WebDAV 根目录下的 /UDaSync/，其中 devices/ 每台设备一个文件， backups/ 保留最近 10 份自动备份。

目录名必须是 ASCII。部分服务需要先在网页端创建应用密码并授权文件夹或读写权限； 例如 123 云盘需在「第三方挂载」中生成应用密码，WebDAV 属于其 VIP 权益，长期高频自动化调用前请先确认服务条款。

连接 123 云盘

使用 123 云盘官方 WebDAV 授权存取书签。服务器地址固定，只需填写第三方挂载页生成的账号与应用密码。

账号信息

未连接

由 UDaSync 固定使用，不需要手动填写；不使用「通用 WebDAV」里的地址。

登录 123 云盘网页端，在「工具中心 → 第三方挂载 → WebDAV 授权管理」里 添加应用。 应用名可填 UDaSync，选择授权文件夹，权限必须选读写； 生成后复制页面显示的账号和应用密码，不要填登录主密码。

WebDAV 挂载属于 123 云盘 VIP 权益；只读权限无法同步。123 云盘用户协议对长期、高频、持续性 WebDAV 自动化调用有保留，公开推荐或长期后台同步前请先确认条款。凭证只保存在本机浏览器配置中。

首次测试或保存时，浏览器会请求访问 https://webdav.123pan.cn/* 的权限。

云端目录

书签快照保存在 123 云盘授权文件夹下的 /UDaSync/，其中 devices/ 每台设备一个文件， backups/ 保留最近 10 份自动备份。

如果添加应用时只授权了某个子文件夹，UDaSync/ 会创建在该子文件夹内。 目录名固定为 ASCII，不要改成中文。

重要前提

请关闭 Chrome / Edge 自带的书签同步，否则两套同步引擎会互相覆盖。 在 chrome://settings/syncSetup（Edge 为 edge://settings/profiles/sync）里 把「书签」取消勾选。

同一个存储账号下，建议一台电脑同时只让一个浏览器在线同步；Chrome 与 Edge 都装的话， 两边会各自同步并逐渐趋同，但不要指望它们实时一致。

关于 UDaSync

一个只做一件事的扩展：把你的书签，通过你自己的 WebDAV、123 云盘或 OneDrive，在多台电脑之间同步。

设计要点

同步范围整棵书签树
冲突策略后写赢 + 墓碑 30 天 + 云端备份 10 份
触发方式书签变动 5 秒防抖 + 启动拉取 + 每 10 分钟轮询
数据位置（坚果云）/UDaSync/devices/<设备>.json.gz
数据位置（通用 WebDAV）<WebDAV 根>/UDaSync/devices/<设备>.json.gz
数据位置（123 云盘）授权文件夹/UDaSync/devices/<设备>.json.gz
数据位置（OneDrive）应用专属文件夹 /UDaSync/devices/<设备>.json.gz

隐私

UDaSync 不采集任何分析数据、不访问与书签无关的网页。网络请求只发往你选择的存储服务： 坚果云、你自己填写的通用 WebDAV、123 云盘，或 Microsoft Graph 的 OneDrive 应用专属文件夹。书签内容只存在本机与你的云端账号里。

排查建议

坚果云失败时依次检查：① 应用密码是否被吊销；② 免费版每月 1GB 上行流量是否用尽； ③ 是否触发 30 分钟 600 次请求限制。通用 WebDAV 失败时检查：① 地址是否以 http:// 或 https:// 开头； ② 是否使用服务商的应用密码；③ 是否允许扩展访问该域名；④ 服务端是否只支持 Digest/OAuth。 123 云盘失败时检查：① 是否在「第三方挂载」生成了账号和应用密码（不是登录密码）； ② 应用权限是否选了「读写」；③ 是否已开通 WebDAV 所需的 VIP 权益；④ 授权文件夹是否仍然有效。 OneDrive 失败时检查：① client ID 是否填写正确； ② Entra 应用是否启用 public client flows；③ 授权是否已过期或被撤销。
