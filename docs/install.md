# 安装与使用

## 1. 选择存储服务

UDaSync 支持两种存储，二选一即可：

- **坚果云 WebDAV**：只准备坚果云账号和应用密码，不需要额外注册云服务
- **OneDrive（个人 Microsoft 账号）**：需要先按 [onedrive-setup.md](onedrive-setup.md) 注册一个 Entra 应用并拿到 client ID

两者不能同时作为当前同步目标；切换不会删除另一边的云端数据。

### 1.1 准备坚果云应用密码

1. 登录 [坚果云](https://www.jianguoyun.com)，进入「账户信息 → 安全选项」
2. 在「第三方应用授权」中点击「添加应用」，名称填 `UDaSync`
3. 复制生成的**应用密码**（不是登录密码，可随时吊销）

扩展会在你的坚果云里创建 `/dav/UDaSync/` 目录，存放 `devices/`（设备快照）与 `backups/`（云端备份）。目录名固定为 ASCII，请勿改成中文路径（坚果云对百分号编码路径返回 404）。

### 1.2 准备 OneDrive client ID

按 [onedrive-setup.md](onedrive-setup.md) 创建 Entra 租户、注册应用并复制 Application (client) ID。只需要这一步，不需要 client secret，也不需要重定向 URI。

## 2. 安装扩展

### 从 Release 安装（推荐）

1. 打开 [Releases](https://github.com/UDaLink/UDaSync/releases)，下载最新的 `UDaSync-x.y.z.zip`
2. 解压到一个固定目录
3. 按下面 Chrome / Edge 的步骤加载解压后的目录

### 从源码构建

```bash
npm ci
npm run build
```

加载 `dist/` 目录。

### Chrome

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择项目中的 `dist/` 目录
4. 建议把 UDaSync 固定到工具栏

### Edge

1. 打开 `edge://extensions`
2. 左下角开启「开发人员模式」
3. 点击「加载解压缩的扩展」，选择 `dist/` 目录

> Chrome 137+ 的品牌版已忽略 `--load-extension` 命令行参数，只能通过上面的界面加载，或使用 Chrome for Testing。日常使用建议直接界面加载。

## 3. 首次连接（第一台电脑）

### 3.1 用坚果云

1. 点击扩展图标 →「打开设置」→ 存储服务选「坚果云 WebDAV」
2. 填写：
   - 服务器地址：`https://dav.jianguoyun.com/dav/`（默认）
   - 账号：坚果云注册邮箱
   - 应用密码：上一步生成的应用密码
   - 云端目录：`UDaSync`（默认）
3. 点击「保存并连接」，通过后会自动做一次同步
4. 若云端为空：本机书签直接上传，并在书签栏生成 `[本机备份] 设备名 时间` 文件夹
5. 若云端已有其他设备的数据：会出现**合并预览**（将新建/更新/移动/删除多少项），确认后才会写入

### 3.2 用 OneDrive

1. 设置页「存储服务」选「OneDrive」
2. 粘贴 Entra 应用的 Application (client) ID，点「连接 OneDrive」
3. 设置页出现一次性代码；按提示打开 Microsoft 登录页，输入代码并同意权限
4. 登录成功后自动执行首次同步；云端已有其他设备时同样先显示合并预览

> OneDrive 首次连接需要完成一次浏览器登录。设备代码通常 15 分钟有效；设置页关闭后本次登录会中断，重新点连接即可。

## 4. 第二台电脑

1. 同样安装扩展，选择与第一台相同的存储服务
2. 坚果云：填同一个账号与应用密码；OneDrive：填同一个 client ID，并用自己的 Microsoft 账号完成设备代码登录
3. 首次同步同样先预览再确认；本机原有书签会先备份
4. 完成后两端应完全一致；之后任意一端改动都会在数秒内推到云端，另一端最迟 10 分钟内拉取

## 5. 必须知道的三件事

1. **关闭浏览器自带书签同步前，先导出书签**：`chrome://bookmarks` → 右上角菜单 → 导出书签。部分 Chrome 版本在关闭「书签」同步项时会**清空本机书签**；UDaSync 检测到这种异常清空会停止上传保护云端，但本机仍需从 HTML 或云端恢复。
   关闭位置：`chrome://settings/syncSetup`（Edge 为 `edge://settings/profiles/sync`），把「书签」取消勾选。
2. **一台电脑的一个浏览器配置文件算一台设备**。Chrome、Edge、不同 profile 都会各自登记，设置页可改名或移除旧设备。
3. **同一账号不要在多处同时首次绑定**：先让一台完成首次同步，再配置下一台，避免两份"首次"互相预览。

## 6. 日常操作

| 操作 | 位置 |
| --- | --- |
| 立即同步 | 工具栏弹窗「立即同步」 |
| 暂停 / 恢复自动同步 | 工具栏弹窗 |
| 查看设备、改名、移除 | 设置页「设备」 |
| 从云端备份回滚 | 设置页「备份」→ 选择时间点 → 恢复 |

| 查看同步日志 | 设置页「日志」 |

## 7. 常见问题

**保存时提示 401**

坚果云账号或应用密码不正确。注意应用密码不是登录密码；若刚重置过，需要重新生成。

**OneDrive 提示 AADSTS16000 / AADSTS50020**

个人 Microsoft 账号默认落在 Microsoft Services 占位租户，不能注册应用。先按 [onedrive-setup.md](onedrive-setup.md) 创建自己的 Entra 租户，再在该租户里注册应用。

**OneDrive 登录后同步 403**

检查应用权限是否包含 `Files.ReadWrite.AppFolder` 和 `User.Read`，以及“允许公共客户端流”是否已开启。修改后断开 OneDrive 重新连接，让用户重新同意权限。

**OneDrive 代码过期 / 登录页关闭了**

重新点「连接 OneDrive」生成新代码。代码通常 15 分钟有效，设置页关闭会中断本次轮询。

**提示 404 / 目录不存在**

云端目录含中文或空格等非 ASCII 字符。坚果云只认真实 UTF-8 路径，请把目录改为 `UDaSync` 这类纯英文名。

**提示 503 / Too many requests**

触发坚果云限流（免费版 600 请求 / 30 分钟）。扩展会自动退避，等待 10–30 分钟即可恢复；也可在设置页把轮询间隔调大（默认 10 分钟已是保守值）。

**书签重复了两份**

多半是两台设备都做了"首次绑定"，或浏览器自带同步也在工作。处理：保留一台为准 → 设置页移除其他设备 → 在云端删除对应快照 → 重新同步；必要时用 `[本机备份]` 恢复。

**关闭自带同步后本机书签全没了**

Chrome 的行为：关闭「书签」同步项可能清空本机书签。UDaSync 会拦截这次异常清空、不污染云端；用设置页「备份」回滚，或导入之前导出的 HTML 即可恢复。

**删除的书签又回来了**

删除依赖墓碑传播，若另一端在墓碑写入前就上传了旧快照，可能出现"复活"。等待下一次同步会再次收敛；仍不消失时，在设置页查看日志确认墓碑是否已上传，或直接从回收站再次删除。

**想换电脑 / 重装浏览器**

不需要重新绑定：装好扩展、填同一账号即可。`adoptOrphans` 会用"同父 + 同名 + 同 URL"把本地新 id 吸附到云端 UUID，避免整棵重复。

**卸载扩展后书签会丢吗**

不会。书签本身在浏览器里，扩展只做同步；卸载前建议先关闭自动同步，避免残留的云端快照影响其他设备。

## 8. 开发者：本地构建与测试

```bash
npm install
npm run build        # dist/
npm run typecheck
npm test             # 单元测试
npm run test:e2e     # 需要 JGY_ACCOUNT / JGY_PASSWORD
```

产物校验脚本会检查 `manifest.json`、后台脚本、两个页面与图标是否齐全。E2E 使用 Chrome for Testing 启动两个独立 profile，验证真实坚果云往返。
